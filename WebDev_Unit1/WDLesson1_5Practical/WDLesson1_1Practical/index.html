Web Technologies

HTML

Hypertext Markup Language (HTML) is the standard markup language for documents designed to be displayed in a web browser. It defines the content and structure of web content. It is often assisted by technologies such as Cascading Style Sheets (CSS) and scripting languages such as JavaScript

CSS

It is a core styling language used by web developers to dictate the visual presentation, layout, and design of a website. While HTML is used to build the underlying structure of a webpage, CSS is applied to control colors, fonts, spacing, positioning, and overall aesthetics.
